\# CareFlow dbt Project



This folder contains the dbt project for the CareFlow Clinical Pathway

Process Mining initiative.



\## Purpose

Transform raw clinical event logs into clean, tested, analysis-ready

models for downstream process mining (PM4Py) and dashboards.



\## Structure

\- models/staging/  -> cleans raw source data

\- models/marts/    -> final business-ready models
